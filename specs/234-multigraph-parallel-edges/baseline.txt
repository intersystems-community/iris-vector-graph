## Notes

- Script: /tmp/baseline234.py (not committed), run with PYTHONPATH on a
  `git archive` of 2b3da99. Before this run the live rdf_edges had been
  returned to the pre-234 shape (ekey and u_spo_graph_ekey dropped), so the
  columns and constraints above are the real pre-change schema.
- Two runs gave the same ^KG dump sha256. create_edge medians were 0.687 ms
  and 0.882 ms, so SC-004 comparisons should allow for that run-to-run noise.
- KGEdgeCount counts (graph, source) pairs, not edges: 10000 here.
- The ledger verify "diverges / unrecorded_writes" result is pre-existing:
  the fixture writes before ledger.enable(), and SC-003 compares against it as
  it stands.
