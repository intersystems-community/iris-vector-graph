# Contract: ObjectScript

Every public class method returns a JSON `%String`, as in 231. On error it returns `{"status": "error", "error": …}` through `..Err`. Python reaches these methods through `_fhir_call` or `schema._call_classmethod`.

## `Graph.KG.PageRank`

```objectscript
ClassMethod RunJson(seedJson As %String, alpha As %Double = 0.85, maxIter As %Integer = 20,
    bidir As %Integer = 0, revWeight As %Double = 1.0, pGraph As %String = "",
    pExclude As %String = "", pLimit As %Integer = 1000) As %String
```

- `pExclude` is `""` or a JSON array of `"p"` or `"Type.p"`.
  - A bare `p` excludes every edge with that predicate.
  - `Type.p` excludes it only where the edge's source key starts with `Type/`. That is the out-edge's owner. For a reverse walk it is the in-edge's source.
- An excluded edge contributes nothing to the walk. The forward divisor counts a node's kept out-edges, and the reverse count skips excluded in-edges.
- `pLimit` is the number of results returned (sorted by score descending). 0 means all. The default of 1000 is the 4.1.0 cap.
- With `pExclude = ""` and `pLimit = 1000`, the output is byte-identical to 4.1.0 (integration test).
- `ClassMethod Run(seedJson, alpha, maxIter, bidir, revWeight, pGraph, pExclude, Output ranks) As %Boolean` is `RunJson`'s walk. It leaves `ranks(node) = score` for callers in IRIS and returns 0 when there are no seeds. `RunJson` sorts and serializes its result.

## `Graph.KG.Eraser`

- `EraseFHIRGraphRows` (changed): the watermark reset also sets `interp_version = NULL`. On a table without the column (SQLCODE -29) it retries without it.
